# 미들웨어 (Middleware)

**미들웨어**란?  
간단하게 말하면 클라이언트에게 요청이 오고 그 요청을 보내기 위해 응답하려는 중간에 목적에 맞게 처리를 하는 (거쳐가는) 함수들이라고 생각하면 된다.

`req`(요청), `res`(응답) 객체 그리고 그 다음의 미들웨어 함수에 대한 엑세스 권한을 갖는 함수를 **미들웨어 함수**라고 한다.

다음 미들웨어 함수에 대한 엑세스는 `next` 함수를 이용해서 다음 미들웨어로 현재 요청을 넘길 수 있다.  
`next`를 통해서 미들웨어는 순차적으로 처리된다.

# HTTP 상태 코드 (HTTP Status Codes)

웹 클라이언트와 앱 서버 사이에서 HTTP 연결이 맺어진 후, 웹 클라이언트가 서버에게 HTTP 요청을 보냈을 경우, 웹 서버는 요청에 따른 처리를 진행 후 그 결과를 웹 클라이언트에 HTTP 응답 메세지로 보낸다.  
서버에서의 처리 결과를 응답 메세지의 상태 라인에 있는 상태 코드 (status code)를 보고 파악할 수 있다.

### 1xx: 정보 제공 (Informational)

- 임시 응답으로 현재 클라이언트의 요청까지는 처리 되었으니 계속 진행하라.

### 2xx: 성공 (Success)

- 클라이언트의 요청이 서버에서 성공적으로 처리
  - **200** 성공
  - **201** 생성됨
  - **202** 허용됨 (요청은 접수, 처리 완료 X)

### 3xx: 리다이렉션 (Redirection)

- 완전한 처리를 위해서 추가 동작이 필요하다.

### 4xx: 오류 (클라이언트 측 문제)

- 없는 페이지 요청, 클라이언트가 요청 메시지를 잘못 보냄
  - **400** 잘못된 요청 (Bad Request)
  - **401** 권한 없음 (Unauthorized)
  - **403** 지정 리소스에 대한 엑세스 금지 (Forbidden)
  - **404** 지정한 리소스를 찾을 수 없음 (Not Found)

### 5xx: 서버 오류 (Server Error)

- 서버 사정으로 오류 (서버 부하, DB 처리 과정 오류 등)
