# 환경 변수

프로세스(컴퓨터에서 실행 중인 프록램)가 컴퓨터에서 동작하는 방식에 영향을 미치는 동적인 값들의 모임이다.

프로세스가 어떠한 작업을 할 때 필요로 하는 정보를 손쉽게 접근 처리/할 수 있도록 해준다.

# CORS

CORS(Cross-Origin Resource Sharing)는 웹 보안 정책의 일환으로, 다른 출처에서 리소스를 불러오는 것을 제한한다.

웹 브라우저가 다른 출처의 리소스를 요청할 때 사용하는 메커니즘이며 , 악의적인 웹사이트가 사용자의 데이터를 탈취하는 것을 방지한다.

# DBCP

DBCP (DB Connection Pool)이란 웹 컨테이너가 실행되면서 DB와 미리 연결 해놓은 객체들을 Pool에 저장해두었다가 , 클라이언트 요청이 오면 Connection을 빌려주고, 처리가 끝나면 다시 connection을 반납받아 pool에 저장하는 방식을 말한다.

매번 사용자가 요청을 할 때마다 드라이버를 로드하고 커넥션 객체를 생성하여 연결하고 종료하기에 매우 비효율적이다. 이런 문제 해결을 위해서 DBCP를 사용한다.

## 특징

- 웹 컨테이너가 실행돠면서 connection 객체를 미리 pool에 생성해 둔다.
- HTTP 요청에 따라 pool에서 connection 객체를 가져다 쓰고 반환한다.
- 이와 같은 방법으로 물리적인 데이터베이스 연결 부하를줄이고 연결 관리를 한다.

# 비동기

동기란 어떤 작업을 실행할 때 그 작업이 끝나기를 기다리는 방식을 의미한다.

반면에 비동기는 이와 반대로 어떤 작업을 실행할 때 그 작업이 완료되지 않더라도 다음 코드를 실행하는 방식을 의미한다.

웹페이지의 반응성 향상 , 네트워크 통신, 병렬 처리, 에러 처리를 위해서 비동기 처리가 필요하다.

js는 싱글 스레드 이기에 , 하나의 스레드에서 모든 작업을 처리할 수 있다. 비동기 처리를 하기 위해서 async와 await을 사용한다.

- async을 함수 앞에 붙여 해당 함수가 비동기 함수임을 나타냄
- await은 비동기 함수의 실행 결과를 기다리는 키워드

```javascript
async function getData() {
  const response = await fetch("/api");
  const data = await response.json();
  return data;
}
```

await인 fetch와 json() 메서드를 기다리고 ,retrun data로 데이터를 반환한다.

# try/catch/finally

프로그램 실행 중 발생하는 오류를 예외라고 하며, 프로그래밍 언어의 문법적인 오류를 에러라고 한다.

예외를 대처할 수 있도록 처리하는 것을 예외 처리라고 한다.

예외 처리 하는 기법은 try/catch/finally문이다.

- try는 예외가 발새할지도 모르는 코드 블록을 정의한다. try 블록 다음에는 catch 절이 이어진다.
- catch는 try블록 내부에서 예외가 발생하는 경우 호출되는 문장 블록이다.
- catch 다음에 finally 블록이 이어지는데, try 블록에서 일어난 일에 관계없이 항상 실행이 보장되어야 할 뒷정리용 코드가 포함된다.
- try는 catch나 finally중 하나 이상이 블록과 꼭 함께 사용되어야 한다.
